# 📝 To-Do List Web App

A simple and elegant **To-Do List web application** built using **HTML, CSS, and JavaScript**.  
This app allows users to **add, edit, complete, and delete tasks** with optional date and time support, while saving tasks to **local storage** for persistence.

## 📂 Project Structure


---

## 🚀 Features
✅ Add tasks with **optional date & time**  
✅ Mark tasks as **completed / undo completion**  
✅ Edit tasks inline and save changes  
✅ Delete tasks instantly  
✅ Data stored in **Local Storage** (tasks remain after refresh)  
✅ Clean, **responsive UI** with modern styling  

---

## 🎮 How to Use
1. Open the `index.html` file in your browser.
2. Type a task in the input field.
3. (Optional) Add a date and/or time for the task.
4. Click **Add Task** (or press Enter).
5. Use:
   - ✅ **Complete** button to mark task as done.
   - ✏️ **Edit** button to modify the task text.
   - 🗑️ **Delete** button to remove the task.

---

## 🛠️ Setup Instructions
1. **Download or clone** this repository.
2. Ensure the files are in the same folder:
   - `index.html`
   - `style.css`
   - `script.js`
3. Open `index.html` in any browser.

---

## 🎨 Customization
- 🎨 **Change theme colors:** Modify `style.css`.
- 🏷️ **Add categories or priorities:** Extend `script.js`.
- ☁️ **Sync with a server:** Replace localStorage with a backend API.
